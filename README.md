# استوديو الكرتون · Cartoon Studio

أداة تعمل في المتصفح لصناعة أفلام كرتونية تعليمية بالعربية: قصة ← شخصيات ← مشاهد ← مراجعة ← إخراج MP4.
لا تحتاج خادمًا ولا حسابًا؛ كل شيء يعمل محليًا على جهازك.

## الاستخدام السريع
- **النسخة المنشورة:** بعد تفعيل Pages يكون الرابط `https://<user>.github.io/<repo>/`.
- **ملف واحد:** حمّل `cartoon-studio.html` من صفحة Releases وافتحه مباشرة.

## التطوير
```bash
npm run dev     # خادم محلي على http://localhost:5173
npm run check   # فحص الملفات وصحة الكود
npm test        # اختبارات المنطق (node --test)
npm run vendor  # مرة واحدة: تنزيل mp4-muxer إلى src/vendor ثم ارفعه مع المشروع
npm run build   # ينتج dist/index.html (ملف واحد مستقل)
```
لا توجد تبعيات npm. الكود سكربتات عادية تُحمَّل بالترتيب المكتوب في `index.html`:

| الملف | المحتوى |
|---|---|
| `00-core` / `01-project` | أدوات عامة، نموذج المشروع، الحفظ، التراجع |
| `02`–`06` | الرسم: الخلفيات، الشخصيات، الفقاعات، المشهد |
| `07-audio` | موسيقى ومؤثرات وجدولة الصوت |
| `08-recording` / `09-offline-export` | تسجيل مباشر وتصدير إطارًا بإطار |
| `10`–`17` | الواجهة، البطاقات، المعرض، الصوت، المنحنيات، المراجعة، التشغيل، التحرير |

عند إضافة ملف جديد في `src/js/` أضف سطر `<script>` له في `index.html` بالترتيب الصحيح (الفحص يتأكد).

## النشر على GitHub
1. أنشئ مستودعًا فارغًا ثم: `git remote add origin <url> && git push -u origin main`.
2. Settings ← Pages ← Source: **GitHub Actions**.
3. لإصدار نسخة: `git tag v14.0.1 && git push --tags`.

## شخصية بوجهك
من تبويب «الشخصيات» اضغط «+ شخصية بوجه من صورة» واختر صورة واضحة لوجهك. يوضع الوجه على جسم كرتوني (ولد أو فتاة) فيتحرك مثل باقي الشخصيات، ويمكنك ضبط التقريب والموضع من بطاقة الشخصية. لا يوجد رسم للفم فوق الصورة؛ يُعبَّر عن الكلام بحركة الرأس.

تُحوَّل الصور الجديدة تلقائيًا لشكل كرتوني (يمكن إلغاء الخانة من نفس التبويب)، ويمكن تحويل صورة مضافة سابقًا بزر «حوّل الصورة لكرتون». هذا فلتر على الصورة نفسها، أما تغيير وضعية الجسم (يد أو رجل مختلفة) فيحتاج صورة لكل وضع.

## ورقة أوضاع
اجعل الشخصية في صورة واحدة مقسومة لشبكة متساوية (الافتراضي 5 أعمدة × صفين = 10 خانات) بخلفية موحدة، وضع في كل خانة وضعًا بهذا الترتيب من اليسار لليمين ومن الأعلى للأسفل: عادي، سعيد، حزين، متفاجئ، غاضب، نعسان، خائف، محب، يتكلم، يمشي. ثم من تبويب «الشخصيات» اضغط «+ شخصية من ورقة أوضاع». الخانة الأولى مطلوبة والفارغة تُتجاهل.

## أشرطة الحركة (مشي، جري، قفز، كلام...)
الشريط صورة واحدة فيها عدة صور متتالية لحركة واحدة، على خلفية سادة (يفضل أخضر #00FF00) وبينها فراغ، والشخصية في كل الصور بنفس المقاس وعلى نفس خط الأرض.

- شخصية جديدة: من تبويب «الشخصيات» اختر الحركة والزاوية وعدد الصور واتجاه الصورة ثم «+ شخصية من شريط حركة».
- لشخصية موجودة: من بطاقتها (قسم «أشرطة الحركة») اختر الحركة والزاوية ثم «+ رفع شريط». يمكن رفع عدة أشرطة لنفس الشخصية.
- تُزال الخلفية تلقائيًا (أخضر أو أزرق أو بينك أو أبيض) مع تنظيف الحواف، وتُفصل الصور عند الفراغات وتُثبَّت على الجسم وخط الأرض.
- الحركات: وقوف وتنفّس، مشي، جري، كلام (فم من مقفول إلى مفتوح)، قفز، تلويح، جلوس. الزوايا: جنب، قدام، ورا.
- اختيار الشريط تلقائي حسب فعل الشخصية واتجاه حركتها: يمين/يسار = جنب (يُقلب حسب الاتجاه)، نحو الكاميرا = قدام، بعيدًا عنها = ورا. إن لم يوجد الشريط تُستخدم أقرب بدائل (الجري يستخدم المشي، والكلام يستخدم الوقوف) ثم الصورة العادية.

## ملاحظات
- التصدير عالي الجودة يستخدم مكتبة `mp4-muxer`. إن وُجد الملف `src/vendor/mp4-muxer.mjs` (بعد `npm run vendor`) يُدمج في النسخة المبنية ويعمل التصدير دون إنترنت؛ وإلا تُحمَّل المكتبة من jsdelivr عند أول تصدير.
- يحتاج Chrome/Edge حديثًا لميزات WebCodecs.
- خط العناوين `src/fonts/Lahb_arphotoshop-Bold.ttf` يحمل علامة ترخيص «مقيَّد» (fsType) من مصمّمه؛ تأكد من حقك في نشره مع الأداة قبل إتاحتها للجمهور.
- الرخصة: MIT.

## شخصيات الدرس وصوت من ملف
- من «الشخصيات» تظهر ألوان **الشعر** و**البنطلون** للولد (والشعر للفتاة). في المعرض ثلاث شخصيات جاهزة للدرس: سامي، صديق سامي، منى.
- في تبويب القصة ← «ابدأ من قالب» ← **درس: فكّر قليلًا.. تربح كثيرًا**: فيلم من ١٢ مشهدًا بحوار ومشاعر.
- في كل جملة حوار زر **📁 صوت من ملف** (حتى 1.7 ميجا للجملة) بجانب التسجيل المباشر؛ تُضبط مدة الجملة على الصوت ويتحرك الفم معه.
