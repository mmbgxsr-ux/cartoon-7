# استوديو الكرتون · Cartoon Studio

أداة تعمل في المتصفح لصناعة أفلام كرتونية تعليمية بالعربية: قصة ← شخصيات ← مشاهد ← مراجعة ← إخراج MP4.
لا تحتاج خادمًا ولا حسابًا؛ كل شيء يعمل محليًا على جهازك.

## الاستخدام السريع
- **النسخة المنشورة:** بعد تفعيل Pages يكون الرابط `https://<user>.github.io/<repo>/`.
- **ملف واحد:** حمّل `cartoon-studio.html` من صفحة Releases وافتحه مباشرة.

## التطوير
```bash
npm run dev     # خادم محلي على http://localhost:5173
npm run check   # فحص الملفات وصحة الكود
npm run build   # ينتج dist/index.html (ملف واحد مستقل)
```
لا توجد تبعيات npm. الكود سكربتات عادية تُحمَّل بالترتيب المكتوب في `index.html`:

| الملف | المحتوى |
|---|---|
| `00-core` / `01-project` | أدوات عامة، نموذج المشروع، الحفظ، التراجع |
| `02`–`06` | الرسم: الخلفيات، الشخصيات، الفقاعات، المشهد |
| `07-audio` | موسيقى ومؤثرات وجدولة الصوت |
| `08-recording` / `09-offline-export` | تسجيل مباشر وتصدير إطارًا بإطار |
| `10`–`17` | الواجهة، البطاقات، المعرض، الصوت، المنحنيات، المراجعة، التشغيل، التحرير |

عند إضافة ملف جديد في `src/js/` أضف سطر `<script>` له في `index.html` بالترتيب الصحيح (الفحص يتأكد).

## النشر على GitHub
1. أنشئ مستودعًا فارغًا ثم: `git remote add origin <url> && git push -u origin main`.
2. Settings ← Pages ← Source: **GitHub Actions**.
3. لإصدار نسخة: `git tag v14.0.1 && git push --tags`.
